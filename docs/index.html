防诈骗检查工具

把可疑的消息、网址或二维码放进来检查一下，再决定要不要回复、付款或打开。

也可以直接在这个页面按 Ctrl+V / ⌘+V 粘贴截图。

常见的诈骗危险信号

  • 投资：“稳赚不赔”“保本”“老师带单”“内部消息”，以及提现前要先交税、手续费或保证金（交了也提不出来）
  • 兼职：点赞、刷单赚钱，先垫付再返佣，“在家用手机轻松日赚”
  • 感情：网上认识、没见过面，却很快说爱你、说要结婚，然后借钱或推荐投资（“杀猪盘”）
  • 共同点：催你马上做决定，叫你“不要告诉家人”，把你引到 LINE、Telegram、WhatsApp 等私聊

觉得可能被骗了

  • 先停止付款，保存好聊天记录和转账记录
  • 日本：警察相谈专线 #9110、消费者热线 188；紧急情况拨 110
  • 中国大陆：全国反诈专线 96110；紧急情况拨 110
  • 当心声称能帮你“追回被骗的钱”的人，这往往是第二次诈骗

消息和图片只在你的浏览器里检查，不会上传。只有勾选“查询域名注册时间”时，域名才会发送给公开的 RDAP 服务器。

※ 本工具根据常见手法判断，结果不代表一定是或一定不是诈骗。觉得不对劲时，请先找身边的人或警察商量。

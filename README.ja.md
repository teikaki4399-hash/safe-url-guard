# safe-url-guard

[English](README.md) | [简体中文](README.zh-CN.md) | **日本語**

**マルウェアサイト・フィッシングサイト・詐欺メッセージ**から身を守るための無料ツール集です。

> **いちばん大切なルール：「お金を取り戻すには、先に払う必要がある」＝ 100% 詐欺です。** 手数料・税金・保証金・凍結解除料・「信用スコア」など名目が何であっても、返金・出金・お金を取り戻す前に払わせるなら、支払いをやめて警察に相談してください。

| ツール | 対象 | できること |
|---|---|---|
| 🛡 [パソコン全体でブロック](#-パソコン全体でブロックすべてのブラウザとアプリ) | パソコン（おすすめ） | システムの hosts ファイルを書き換え、**すべてのブラウザとアプリ**から危険なサイトに接続できないようにします。毎日自動更新 |

## 🛡 パソコン全体でブロック（すべてのブラウザとアプリ）

ブロックリストをシステムの hosts ファイルに書き込むので、Chrome・Edge・Firefox・Safari をはじめ、どのアプリからもリストに載ったサイトに接続できなくなります。起動時と1日1回、自動で更新されます。

**始める前に：** Python 3 をインストールしてください（Windows は [python.org](https://www.python.org/downloads/) から。「Add python.exe to PATH」にチェック）。次にこのリポジトリをダウンロード（**Code → Download ZIP**）して展開します。

**Windows：** スタートメニューで「PowerShell」を検索して右クリックし、**管理者として実行** を選んでから、次を実行します：

```powershell
cd path\to\safe-url-guard-main
python hosts_guard.py install
```

**macOS：** まずフォルダを `/Users/Shared/` に移動してください。macOS はバックグラウンドの処理が「ダウンロード」「デスクトップ」「書類」を読むことを制限しているため、そこに置くと毎日の更新が失敗します。

```sh
mv ~/Downloads/safe-url-guard-main /Users/Shared/safe-url-guard
cd /Users/Shared/safe-url-guard
sudo python3 hosts_guard.py install
```

python.org からインストールした Python で `CERTIFICATE_VERIFY_FAILED` と表示された場合は、「アプリケーション → Python 3.x」にある **Install Certificates.command** をダブルクリックしてから、もう一度実行してください。

**Linux：**

```sh
cd path/to/safe-url-guard-main
sudo python3 hosts_guard.py install
```

- 状態の確認：`python hosts_guard.py status`
- アンインストール：`python hosts_guard.py uninstall`（Windows は管理者として、macOS / Linux は `sudo` を付けて）。最初の変更の前に、元の hosts ファイルは `hosts.safe-url-guard.bak` としてバックアップされます。
- **インストール後はフォルダを移動・削除しないでください。** 毎日の更新はこのフォルダから実行されます。
- ブラウザで「セキュア DNS（DNS over HTTPS）」がオンになっていると hosts ファイルが使われないことがあるので、**下のブラウザ拡張機能も入れてください**。

## 🧩 ブラウザ拡張機能（おすすめ）

- ブラウザの起動時に自動で動き、24時間ごとにブロックリストを更新します
- リストに載ったサイト（そのサブドメインを含む）を開くと、代わりに警告ページが表示されます。**「このまま進む」ボタンはありません。**
- ブロックしたいサイトを自分で追加できます。安全なサイトが誤ってブロックされた場合は、設定で許可できます
- **「振り込む前にひと呼吸」：** ネットバンキングや決済の振込・送金ページらしいページ（アドレスや見出しに「振込」「送金」「转账」「transfer」などの言葉があり、金額の入力欄がある）を開くと、サイトごと・ブラウザのセッションごとに1回、確認のチェックリストが表示されます。「振込先はネットで知り合い、会ったことのない人ですか？」「返金や出金の前に、先にお金を払う必要があると言われましたか？」「誰にも言わないでと言われましたか？」など。1つでも「はい」と答えると強い警告が表示され、「続ける」ボタンは15秒待たないと押せません。振込をブロックすることはなく、設定でオフにできます
- **新しいドメインの警告：** 開いたサイトが**登録から30日未満**のとき、ページ上部に赤い警告バーを表示します（サイトはブロックしません）。登録日は [RDAP](https://www.icann.org/rdap) で調べます。プライバシーについては下の注記を見てください。公開 RDAP サーバーがないドメインの末尾もあり、その場合は何も表示されません

### インストール方法（Chrome / Edge）

1. このリポジトリをダウンロード：**Code → Download ZIP** を押して展開します
2. アドレスバーに `chrome://extensions`（Edge は `edge://extensions`）と入力します
3. 右上の **デベロッパー モード** をオンにします
4. **パッケージ化されていない拡張機能を読み込む** を押し、展開した `extension` フォルダを選びます
5. ツールバーの 🛡 アイコンを押して「… 件の危険なサイトをブロック中」と表示されれば完了です

> ブラウザに「すべてのサイトのデータの読み取りと変更」の権限が必要だと表示されます。これは**危険なサイトを警告ページに転送する**ために必要です（[Chrome のドキュメント](https://developer.chrome.com/docs/extensions/reference/api/declarativeNetRequest)）。振込ページを見分けるために、拡張機能はページのタイトル・見出し・入力欄のラベルを**ブラウザの中だけで**確認します。入力した内容は読みません。新しいドメインの警告のために、開いたサイトの**ドメイン名だけ**（例：`shop.example.com`。完全なアドレスではありません）を、そのドメインの末尾を管理する公開 RDAP サーバー（[IANA のブートストラップファイル](https://data.iana.org/rdap/dns.json)で探します）に送信します。結果は約1か月キャッシュされます。送信したくない場合は、設定で「新しいドメインの警告バー」をオフにしてください。それ以外の情報はどこにも送信しません。コードはすべてこのリポジトリで公開しています。

Firefox にはまだ対応していません（Chrome 方式のバックグラウンド処理を使っているため）。Firefox を使う場合は、[パソコン全体でブロック](#-パソコン全体でブロックすべてのブラウザとアプリ)を使ってください。

## 🌐 ウェブ版チェッカー

**https://teikaki4399-hash.github.io/safe-url-guard/?lang=ja**

- **メッセージ：** SMS・LINE・メール・DM を貼り付けて、よくある詐欺の言い回しをチェック
- **リンク：** あやしい特徴（似た文字を使ったドメイン、IP アドレスの直接指定など）と、ドメインがいつ登録されたかをチェック
- **QRコード：** QRコード画像の中のリンクを読み取り、開く前にチェック

## 📱 スマートフォンでの使い方

スマホではパソコンと同じ方法でブロックすることはできません（iPhone の Safari 拡張機能は App Store で配布する必要があります）。代わりに次を組み合わせてください：

1. **ウェブ版チェッカーをホーム画面に追加：** スマホで https://teikaki4399-hash.github.io/safe-url-guard/?lang=ja を開きます
   - iPhone（Safari）：共有ボタン → **ホーム画面に追加**
   - Android（Chrome）：⋮ → **ホーム画面に追加**

   あやしいメッセージ・リンク・QRコードを受け取ったら、**まず貼り付けてチェック**してください。QRコードはスクリーンショットを撮り、「QRコード」タブで選びます。
2. **スマホ本体の保護機能をオンに：**
   - iPhone：設定 → Safari → **「詐欺Webサイトの警告」** をオン（新しい iOS では 設定 → アプリ → Safari）
   - Android（Chrome）：⋮ → 設定 → プライバシーとセキュリティ → セーフ ブラウジング → **保護強化機能**
3. **悪意のあるドメインをブロックする DNS サービスを使う（スマホ全体が対象）：** たとえば非営利の [Quad9](https://quad9.net/) は、既知の悪意のあるドメインをブロックします。
   - Android 9 以降：設定 → ネットワークとインターネット → **プライベート DNS** →「プライベート DNS プロバイダのホスト名」→ `dns.quad9.net`（メニュー名は機種によって異なります）
   - iPhone：構成プロファイルが必要です。Quad9 のウェブサイトの手順に従ってください

## 🐍 Python コマンドラインツール

Python 3.8 以上、標準ライブラリのみ。QRコードのチェックには OpenCV も必要です。表示は英語または中国語です（日本語には未対応）。

```sh
git clone https://github.com/teikaki4399-hash/safe-url-guard.git
cd safe-url-guard

# リンクのチェック（先にブロックリストをダウンロード。1日1回がおすすめ）
python3 safe_url_guard.py update
python3 safe_url_guard.py check https://example.com
python3 safe_url_guard.py open https://example.com     # 危険なサイトはブロック、あやしいサイトは確認してから開く
python3 safe_url_guard.py hosts > blocklist-hosts.txt  # hosts ファイル形式のブロックリスト

# 詐欺メッセージのチェック
python3 scam_check.py "元本保証で必ず儲かります。まずは少しだけ入金してください"
python3 scam_check.py -f message.txt --online           # --online：リンク先ドメインの登録日も調べる

# ドメインの登録日
python3 domain_age.py https://shop.example.com

# QRコード
pip install opencv-python-headless
python3 qr_check.py qr.png
```

独自のリストは `~/.cache/safe_url_guard/` に置きます：`allowlist.txt`（許可リスト）と `denylist.txt`（ブロックリスト）、1行に1ドメイン。

## 判定の仕組み

| チェック | 情報源 |
|---|---|
| フィッシングサイト | [OpenPhish](https://openphish.com/phishing_feeds.html) の公開ブロックリスト（Community Feed） |
| マルウェア・フィッシング・詐欺サイト | [HaGeZi Threat Intelligence Feeds](https://github.com/hagezi/dns-blocklists#tif) の **mini** 版（[GPL-3.0](https://github.com/hagezi/dns-blocklists/blob/main/LICENSE)。リストのヘッダーに「8時間で期限切れ」と書かれています。2026年11月時点で約18万ドメイン）。公開ダウンロードが2026年11月に終了した（HTTP 410）URLhaus の代わりです |
| 確認済みの詐欺サイト | このリポジトリで管理している [`extension/builtin_blocklist.txt`](extension/builtin_blocklist.txt) |
| ドメインの登録日 | [RDAP](https://www.icann.org/rdap)（RFC 9082/9083）。問い合わせ先は [IANA のブートストラップファイル](https://data.iana.org/rdap/dns.json)で探します。30日未満は「非常にあやしい」、180日未満は「注意」 |
| 詐欺の言い回し | [`docs/scam_rules.json`](docs/scam_rules.json) のルール（中国語・日本語・英語の言い回し）。危険なサインごとに点数が加わり、「恋愛＋お金」「副業＋立て替え」のような危険な組み合わせにはさらに加点されます |

## 限界（必ず読んでください）

- ブロックリストに載るのは**すでに報告されたサイト**だけです。できたばかりの詐欺サイトは検出できないことがあります。
- メッセージのチェックは、よくある言い回ししか知りません。**引っかからなかったからといって安全とは限りません。** 相手が**お金や認証コードを求めてきたり、誰にも言わないでと言ってきたり**したら、まず信頼できる人か警察に相談してください。
- ブラウザ本体の保護機能もオンにしておいてください（Chrome / Firefox の [Google セーフ ブラウジング](https://safebrowsing.google.com/)、Edge の Microsoft Defender SmartScreen など）。

## よくある手口：「信用スコア」・返金詐欺

1. 「プラットフォームの受付」を名乗る人物が Telegram などで連絡してきて、出会い系のプラットフォームを紹介する
2. 「登録」のために「専用アプリ」のダウンロードや、会費・保証金の支払いを求められる
3. 支払うと、「操作ミス」「信用スコアが下がった」「アカウントがロックされた」と言われ、返金や出金の前に「スコア回復」のための支払いを求められる
4. 信用させるために、最初に少額の「認証用保証金」（例：300）を払わせ、少額（例：600）を本当に振り込んでくる。**これはその後のずっと大きな支払いのための餌です。**
5. 出金しようとすると「返金担当」や「出金部門」が現れ、「認証用保証金」「二次認証」を求めたり、金額を「分割」する必要があると言ったりする
6. 「200%保証」「すべて実名認証済みの口座」「詐欺のプラットフォームがこんなに長く続くと思う？」「出金できなければ警察に通報していい」「これだけ大きなプラットフォームが、たかが数千のために看板を汚すわけがない」と、しつこく安心させようとする
7. いくら払っても、また払う理由が出てくる。**お金を取り戻すために「スコア回復」「凍結解除」「審査通過」の支払いが必要だと言われたら、支払いをやめて警察に相談してください。**

## 詐欺師が使う心理テクニック

詐欺は人の考え方に合わせて設計されています。公的な注意喚起や警察の事例では、同じテクニックが何度も出てきます：

| テクニック | どんな形で現れるか |
|---|---|
| **恐怖** | 「口座が凍結される」「犯罪の疑いがある」「操作ミスをした」 |
| **欲・「今回だけ」** | 最初の少額の利益や、本当に届く少額の出金。もっと大きな支払いのための餌 |
| **サクラ** | 全員が利益のスクショを投稿するグループ。中国の警察が公表した事例では、54人の「副業グループ」のうち53人が詐欺グループのメンバーでした（[gmw.cn](https://m.gmw.cn/2026-08/24/content_1304553152.htm)） |
| **希少性・焦り** | 「残り3枠」「30分以内に」、絶え間ないメッセージ |
| **「損を取り戻す」** | 「凍結解除」「出金」のための追加の手数料。その後、手数料を求める「被害回復」の誘い（二次被害の詐欺） |
| **小さな文字** | 金額や必須の「コード」を小さな文字や薄い色で書き、後で「やり方が間違っていた」と言う |
| **独自のアプリやチャット** | リンクから入れさせるアプリや、サイト上に出てくるチャット窓。偽アプリは偽の残高を表示したり、スマホを乗っ取ったりできます |
| **孤立させる** | 「家族や銀行には言わないで」、Telegram や非公開グループへの誘導 |

出典：警察庁の SNS 型投資・ロマンス詐欺の統計（[npa.go.jp](https://www.npa.go.jp/bureau/safetylife/sos47/new-topics/260420/01.html)）、FBI IC3 の暗号資産投資詐欺に関する警告（[ic3.gov](https://www.ic3.gov/PSA/2022/psa221003)）、画面共有や偽アプリを使った詐欺に関する中国の警察の報告（[news.cn](https://www.news.cn/legal/20250423/149dfe212a0b49efb6937d582e058bb8/c.html)）。

## 詐欺にあったかもしれないと思ったら

- 支払いをやめてください。やり取りと支払いの記録はすべて残しておいてください。
- 日本：警察相談専用電話 **#9110**、消費者ホットライン **188**（[消費者庁](https://www.caa.go.jp/policies/policy/local_cooperation/local_consumer_administration/hotline/)）、緊急時は **110**
- 中国本土：詐欺対策ホットライン **96110**、緊急時は **110**
- その他の国・地域：できるだけ早く地元の警察と銀行に連絡してください
- **「被害金を取り戻します」**と持ちかける人に注意してください。多くは二次被害の詐欺です
- 詐欺師が送ってくる「身分証の写真」は、実在の人から盗まれたものであることが多く、何の証明にもなりません
